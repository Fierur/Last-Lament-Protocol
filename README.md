# LAST LAMENT

### *A Dark Fantasy Action Metroidvania built with Unity*

*"Power demands sacrifice. Every emotion you trade makes you stronger... and less human."*

</p>

---

## 🎮 About

**Last Lament** is a dark fantasy 2D Action Metroidvania where progression is purchased with the protagonist's emotions instead of traditional experience points.

Every upgrade permanently changes both gameplay and narrative.

The stronger Edric becomes, the more of his humanity disappears.

This project is currently being developed using **Unity 6 (URP)** as both a personal indie game and a university graduation project.

---

## ✨ Core Features

- ⚔️ Precision-based combat
- 🛡️ Parry & Execution System
- ❤️ Emotion Bargain Progression
- 🌑 Atmospheric World Exploration
- 🗺️ Metroidvania Ability Gating
- 💀 Death Loop Meta Progression
- 📖 Environmental Storytelling
- 🎼 Dark Fantasy Narrative

---

## 🧠 Unique Selling Point

Unlike traditional Metroidvania games where players gain power through experience or skill trees,

**Last Lament uses emotions as its progression currency.**

Every pact grants greater strength while permanently stripping away part of Edric's humanity.

Gameplay progression and narrative progression become the same system.

## 📖 Lore

Edric Ravenshade, a former noble turned frontier guard, lost everything during the Parade of Monsters.

Standing before absolute despair, he accepts a forbidden pact with Vaelgor.

He will gain unimaginable power.

The price...

is every emotion that made him human.
